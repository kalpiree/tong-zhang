# Tong Zhang’s academic website

This static website follows the layout of Nitin Bisht’s academic website and uses a dark colour scheme. It runs without a build step.

## Publish on GitHub Pages

1. Copy the contents of this directory, including `.nojekyll`, to the root of the intended GitHub repository.
2. Commit and push the files to the `main` branch.
3. In the repository’s **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, and save.
4. Open the URL displayed by GitHub Pages when deployment finishes. All internal links are relative, so the same files work at an account or project site.

## Update content

Edit `index.html`, `publications.html`, `talks.html`, and `cv.html` directly. Replace `assets/Tong_Zhang_Academic_CV.pdf` to update the downloadable academic CV. Shared styling is in `style.css`.
